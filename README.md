# Naughty Coffee

A responsive, frontend-only coffee shop homepage built with Next.js App Router, React, Tailwind CSS 4, and Lucide icons.

## Local development

Install dependencies with `npm install`, then start the development server with `npm run dev`.

No build or test commands were run during creation.

## Included

- Hero, brand story, filterable featured coffees, café experience, masonry gallery, visit section, and footer.
- Accessible native dialogs for drink details and gallery previews; session-only favourite selections.
- Mobile navigation, anchor links, scroll reveals, subtle parallax, and reduced-motion support.
- A brand-inspired typographic wordmark. Replace it with the approved Naughty Coffee logo when available.

## Proposal content

Photography loads from Unsplash image URLs and fonts load from Google Fonts; both require an internet connection. Images are illustrative, not verified photos of Naughty Coffee. Menu descriptions are concept copy. Location, hours, contact information, and social URLs are deliberately unconfigured until confirmed. Contact and social buttons explain this in a dialog. The map is a styled placeholder, not an interactive map. Update content in `components/homepage.tsx` and styling in `app/globals.css`.

No inner pages, backend, authentication, CMS, or API integrations are included.
